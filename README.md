# حزمة قِمّة التعليمية

هذه الحزمة تجمع ملفات الواجهة التي تعمل معًا. ضع ملفات HTML وCSS وJavaScript في مجلد الموقع نفسه، مع الاحتفاظ بمجلد Supabase كما هو.

## تفعيل المساعد الذكي
المساعد يحتاج مفتاح OpenAI محفوظًا في Supabase Edge Function Secrets باسم OPENAI_API_KEY. أضِفه من لوحة Supabase ضمن إعدادات Edge Functions/Secrets. لا تضع مفتاح OpenAI في ملفات الموقع أو GitHub. الاستخدام يخضع لتسعير حساب OpenAI؛ الدالة تحدّ الاستخدام إلى 20 طلبًا لكل حساب يوميًا.

## العمر والخصوصية
يحسب الموقع الفئة العمرية في المتصفح ويرسل الفئة فقط؛ لا يحفظ تاريخ الميلاد. الحسابات الأصغر من 13 سنة تحتاج تأكيد موافقة ولي الأمر كما يظهر في التسجيل. هذا التأكيد داخل النموذج ليس تحققًا قانونيًا من هوية ولي الأمر.
مجتمع الطلاب يعرض المنشورات بحسب الفئة العمرية والصف الدراسي، وبحسب نظام ومسار تانية ثانوي عند الحاجة. لا يعرض البريد الإلكتروني أو تاريخ الميلاد. لا تشارك بيانات التواصل أو العنوان أو الصور، وتحقق من الفيديوهات الخارجية قبل استخدامها مع الطلاب الصغار.

## الملفات
- index.html و style.css و script.js و manifest.json: لوحة الدراسة.
- account.html و account.js: التسجيل والدخول.
- student.js: ربط المساعد والمجتمع وملف الطالب الدراسي.
- supabase/functions/qimma-tutor/index.ts: المساعد الآمن من جهة الخادم.
- supabase/migrations/: مخطط الجداول وسياسات الوصول وحد الاستخدام والمجموعات حسب الصف.

اتصال Supabase الحالي يعتمد مفتاح النشر العام الموجود في إعدادات المشروع. لا تضف أبدًا service_role أو مفتاح OpenAI إلى كود المتصفح.


## واجهة المسارات ومصادر المدرسين
تضيف الصفحة الرئيسية لوحة أصلية للمسارات: خطوات تعلم الفيزياء، مسار جانبي للإنجليزي، وروابط مباشرة للمنصات الرسمية لبسطتهالك وأستاذ محمد عبد المعبود وإنجليشاوي. الروابط لمواقع خارجية وقد تتطلب حسابًا أو اشتراكًا. التصميم يستلهم أنماط تنظيم المحتوى والاختبارات والتنقل ولا ينسخ أصول أو نصوص تلك المواقع.
