# قِمّة — منصة التعليم الذكية

واجهة أولية مبنية وفق التصميم المرجعي الذي أرسله المستخدم. تتضمن لوحة الطالب، التحديات، الامتحانات التجريبية، مكتبة المواد، المساعد التجريبي، مجتمع الطلاب، وإعدادات الحساب.

ملاحظة: المساعد والاختبارات والمشاركات تجريبية من جهة الواجهة فقط، وتحتاج خدمات خلفية لبيانات حقيقية وحسابات آمنة.
